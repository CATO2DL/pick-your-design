# Small Hours — initial brief

This is a fictional, public demonstration brief for testing Pick Your Design, not a commissioned business or a claim about an existing venue.

Create a one-page English concept website for a small reading space. The intended reader is an adult interested in quiet shared reading. Explain the concept, suggest what to bring, and answer basic questions. Do not invent a real address, opening hours, booking availability, price, testimonial, email, or membership system. Use original proposed copy and identify the page as a concept.

First show real website references and obtain visual feedback. Save a detailed specification before creating a minimal static page. The repository task authorizes this example's implementation and public source publication. It does not authorize operating a venue or adding a signup backend. No image generation is needed at any stage. Any redistributed photograph must have a suitable recorded license.

**Provenance:** the name, audience, concept, content, and numeric design parameters are demonstration/design suggestions. The preference for a large photograph with centered copy was confirmed by a person after viewing real reference boards. A later palette revision is a labeled test input, not another user preference.
